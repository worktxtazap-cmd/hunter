ПРОТОКОЛ РАБОТЫ
- Ассистент НЕ ходит по URL сам: квота на скрапинг выжжена, web_search даёт мусор.
- Контур: ассистент даёт блок -> юзер вставляет в Termius -> скриншот -> ассистент
  читает картинку зрением. Писать и запускать можно вслепую, читать — только скриншотом.
- Перед каждым блоком писать: "вставь в Termius, скинь скриншот".
- Блоки короткими порциями, юзер с телефона.
- Пока скрипт ждёт ввод, блоки вставлять нельзя — уйдёт в stdin. Сначала Ctrl+C,
  дождаться приглашения ubuntu@...$
- Песочница html_sandbox наружу не ходит, доступен только cdn.jsdelivr.net.
- Длинные прогоны пускать через nohup или systemd: обрыв SSH убивает foreground.
